# Security policy

Version 0.2.x is the supported security baseline. Upgrade from 0.1.0 before using
POP3 or sending sensitive mail. Read [the security model](docs/SECURITY.md) and
[migration guide](docs/MIGRATION-0.2.md).

Report a suspected vulnerability privately using GitHub's "Report a vulnerability"
option in this repository's Security tab when available. If private reporting is
not enabled, contact the maintainer through their published GitHub contact method;
do not disclose exploitable details in a public issue before coordination.

Include the affected version, a minimal reproduction using synthetic data,
expected/actual behavior, and relevant redacted diagnostics. Never include mailbox
passwords, bearer tokens, private keys, actual message bodies, PSTs, or attachments.
The project does not promise a response SLA.
